编辑文稿

粘贴或修改中文文稿。括号（含嵌套注释）会保留显示，语音跟随时略过。空白行自动移除，段落没有额外间距；全文统一使用左侧设置的行距。Markdown 保留非空行原文。

共用本地模型

只下载你选的一种。模型保存在应用外，可供支持同一 MLX 格式的软件引用；更新或卸载顺稿不会删除模型。已有 PyTorch / BF16 权重不能直接用于这里的 MLX 8bit 版本。



把注意力留给表达
导入 TXT、Markdown，或直接粘贴文稿。首次加载成功后会记住模型，下次启动在后台恢复。输入默认跟随系统，也可在加载前选择并记住设备。点击开始跟随才采集声音。首次开始会请求系统麦克风权限。
让跟随更稳
跟随以中文与拼音的模糊匹配为依据。漏字、同音识别错误和短暂发挥后，可在说回文稿时恢复。跨段跳读需要两次不同识别结果确认。完全改写且没有共同词句时会停住；点击目标句能立即定位。
重复段落缺少上下文时会停住，继续念区分性的下一句即可。安静时不会自动前进。此程序不录制或保存原始麦克风音频，也不联网识别。
基本操作
空格暂停 / 继续；↑ ↓换句；← →调定速速度。鼠标滚轮、点击文字、文稿旁竖向进度条和关键词搜索均可定位。语音与定速切换保留位置，并暂停以便准备。
镜像只作用于文稿，按钮仍正常可操作。⌃⌘F 或全屏按钮进入 / 退出全屏，Esc 退出。窗口可拖动与缩放，置顶可随时关闭。
保存与隐私
「保存」写入当前文稿文件；「另存为」可用 .sgprompt 保存原稿、位置和样式，.txt / .md 仅保存原文。编辑会话和设置在用户应用支持目录自动恢复。自动恢复不覆盖外部原稿。语音只进入所选的本地 MLX 模型。
